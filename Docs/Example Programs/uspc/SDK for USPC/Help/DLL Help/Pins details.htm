Pins details:

 

USPC supplies logical Outputs and analogue Outputs.

USPC logical Outputs can be assigned with none, one or several alarms or even controlled by an application.

USPC analogue Outputs can only be assigned with none or one measurement.

 

 

Logical Outputs:

 

You can use the following logical outputs pins:

Pin 7, 8, 9, 10, 11, 12, 15, 18 and 19.  see electric specification

 

In order to control one or several logical outputs, you have to do as follow:

1 – define an array of pins to control and define an array of initial state (parameter = “pins_output_list”)

2 – set/reset one or several outputs (parameter = “pins_set_output”)

 

In order to get one or several alarms on one pin, you have to do as follow:

1 – define an array of alarms codes (8 max.) for one pin (parameter = “pin”)

 

Code

Description

2999

Not used

2000

Card ready

2001

Alarm of gate IF

2002

Alarm of gate 1

2003

Alarm of gate 2

2004

Alarm thickness mini. of gate 1

2005

Alarm thickness mini. of gate 2

2006

Alarm thickness maxi. of gate 1

2007

Alarm thickness maxi. of gate 2

2008

Alarm coupling of gate 1

2009

Alarm coupling of gate 2

 

Remark:

1-The “PCXUS_Load” function clears pins output list. So, you have to set pins output list after loading an UT file.

2-If you assign an alarm on one pin and put this pin into the list of pins to be controlled by software then priority is given to software.

3-All outputs are cleared when you call the parameter “pin”.

 

 

Analogue outputs:

 

You can use the following Analogue Outputs pins:

Pin 1, 2, 3, 4, 23, 24, 25 and 26. see electric specification

 

In order to get one measurement on one pin, you have to do as follows:

1 – define an array of analogues codes (only one code) for one pin (parameter = “pin”)

 

Code

Description

1999

Not used

1000

Analogue amplitude of gate 1

1001

Analogue amplitude of gate 2

1002

Analogue thickness of gate 1

1003

Analogue thickness of gate 2

1004

Analogue coupling of gate 1

1005

Analogue coupling of gate 2

1006

Extension Gate 1

1007

Extension Gate 2

 

 

 

Example

 

VC++ example:

 

Double PinAlarms[8],  PinAnalogues [8];

Double PinNumber;

Double PinsOutputList[9] , InitialStat[9] , CurrentStat[9];

 

PinNumber =8-1;                       // Pin 8  ( Warning : Pin number start at 0)

For(I=0;I<8;I++)PinAlarms[i]=0;  // Initialisation of PinAlarms array

PinAlarms[0]=2002;                  // Set Alarm Gate 1 and Alarm Gate 2 on pin 8

PinAlarms[1]=2003;                 

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pin”, PinNumber, PinAlarms, NULL, NULL, &Clip)

…

PinNumber =1-1                                   // Pin 1  ( Warning : Pin number start at 0)

For(I=0;I<8;I++) PinAnalogues [i]=0;       // Initialisation of PinAlarms array

PinAnalogues [0]=1000;                        // Set Amplitude of Gate 1 on pin 8

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pin”, PinNumber, PinAnalogues, NULL, NULL, &Clip)

…

PinsOutputList[0]=7-1;              // Pin 7 will be controlled by software

PinsOutputList[1]=18-1;             // Pin 18 will be controlled by software

PinsOutputList[2]=-1;                // -1 to terminate the list

InitialStat[0]=0;                         // Pin 7 is OFF

InitialStat[1]=1;                         // Pin 18 is ON

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pins_output_list”, NULL, PinsOutputList, InitialStat, NULL, &Clip)

…

PinsOutputList[0]=18-1;             // Change only Pin 18

PinsOutputList[1]=-1;                // -1 to terminate the list

CurrentStat[0]=0;                      // switch off Pin 18

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pins_set_output”, NULL, PinsOutputList, CurrentStat, NULL, &Clip)

…

PinsOutputList[0]=18-1;             // Change Pin 18

PinsOutputList[1]=7-1;              // Change Pin 7

PinsOutputList[2]=-1;                // -1 to terminate the list

CurrentStat[0]=0;                      // switch off Pin 18

CurrentStat[1]=1;                      // switch on Pin 7

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pins_set_output”, NULL, PinsOutputList, CurrentStat, NULL, &Clip)

…

PinsOutputList[0]=-1;                // Clear output list

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pins_output_list”, NULL, PinsOutputList, NULL, NULL, &Clip)

…

PinsOutputList[0]=15-1;             // Change only Pin 15

PinsOutputList[1]=-1;                // -1 to terminate the list

CurrentStat[0]=0;                      // switch off Pin 15

Error = PCXUS_WRITE(hPCUS, Board, 0, 0, “pins_set_output”, NULL, PinsOutputList, CurrentStat, NULL, &Clip) // This code makes a error (pin 15 is not into output list)
