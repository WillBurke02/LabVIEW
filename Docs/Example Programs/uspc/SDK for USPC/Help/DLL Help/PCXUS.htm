DLL description

 

Since version 3.0, DLL has been developed to be very easy to use (less than 10 functions are necessaries).

Now, you don’t need to know driver specifications, you don’t need to initialize USPC cards and any serial communication programs are necessaries with MUX and RCPP extension cards.

You use DLL like a file with open, close, read and write functions.
