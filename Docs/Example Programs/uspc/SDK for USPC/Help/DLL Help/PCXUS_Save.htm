Update 20 October 2005

 

DLL Version 8.1.x

 

Compatibily:

compatibility since DLL version 3.0

 

 

Function:

ULONG WINAPI PCXUS_Save(int Board, int Test, LPCSTR file)

 

Description:

This function saves your parameters into a file

 

Arguments:

Board               Board number to be saved (-1 = all boards)

Test                 Test to be saved (-1 = all tests) (only for USPC with MUX extension)

File                  ASCII file name

 

Returns:

0 if no error
