PCXUS_ACQ_GET_STATUS.htm

Update 15 October 2002

 

DLL Version 5.0

 

Compatibility:

Software : DLL version 5.0

Platforms: Windows 2000/NT4/XP (unsupported on Windows 98)

 

Function:

ULONG WINAPI PCXUS_ACQ_GET_STATUS(int Board, ULONG *Status, ULONG *NumberOfScansAcquired, ULONG *NumberOfScansRead, ULONG *BufferSize, ULONG *ScanSize)

 

Description:

This function gets information about current acquisition configuration.

 

Arguments:

Board                                       Board number to be set up( 0 to 9).

 

Status                                      Pointer to Status

                                   0: ACQ_NO_CONFIGURED

                                                           1: ACQ_RUNNING

                                                           2: ACQ_FINISHED_WITH_SCANSBACKLOG

                                                           3: ACQ_FINISHED_WITHOUT_SCANSBACKLOG

                                                           4: ACQ_WAITING_START

                                                           5: ACQ_FIFO_ERROR

                                                           6: ACQ_BUFFER_FULL

                                                           7: ACQ_BLOC_SIZE_ERROR

 

NumberOfScansAcquired           Pointer to number of Scans acquired.

 

NumberOfScansRead                Pointer to number of Scans read.

 

BufferSize                                Pointer to buffer size (in number of Scans)

 

ScanSize                                 Pointer to scan size (in number of DWORD)

                                                          

Returns:

0         no error

Status, NumberOfScansAcquired, NumberOfScansRead, BufferSize and ScanSize are updated.
