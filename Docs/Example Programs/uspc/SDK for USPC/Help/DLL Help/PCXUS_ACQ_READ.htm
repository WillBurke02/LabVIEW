Updated 10 January 2008

 

 

Compatibility:

Platforms: Windows 2000/NT4/XP (unsupported on Windows 98)

 

Function:

ULONG WINAPI PCXUS_ACQ_READ(ULONG hPCXUS, int Board, ULONG NumberOfScansToRead, int TimeOut, ULONG *NumberRead, ULONG *ScansBacklog, UCHAR *pData)

 

Description:

This function reads Scans into the buffer.

 

Arguments:

HPCXUS                                  Your access number (see PCXUS_Open function).

 

Board                                       Board number to be set up( 0 to 9).

 

NumberOfScansToRead            Number of scans to read into buffer.

                                                           Negative value: read all Scans into the buffer

                                                           0: read the buffer when is full

                                                           Positive value: (1 up to buffer size) read this number of Scans

 

TimeOut                                   Define the time out value in order to get the number of scans

                                                           0: read immediately

                                                           Positive value: wait this value (ms) before to set a time out error

 

NumberRead                            Pointer to the number of scans read.

 

ScansBacklog                          Pointer to number of scans remaining into the buffer.

 

pData                                     Pointer to scans read.

 

Returns:

0                      no error

0x82000100      board number error

0x82000C00      access number error

0x82000C08      access number error (this board is configured by another application) (This error code is managed since DLL 10.0.0)

0x82000700      bad parameter (TimeOut<0 or NumberToRead>BufferSize)

0x8200000B      acquisition not configured

0x8200000E      incomplete acquisition

0x8200000F      time out error

0x82000010      wait start error

0x82000011      insufficient memories error

0x82000012      overwrite error

0x82000013      FIFO error

0x82000022      FIFO overflow error

 

NumberRead, ScansBacklog and pData are updated.

Remark:

When using the acquisition modes, which are controlled by the alarm signals, remember that these alarms are set after a number of pulses determined by the alarm filters values.

Consequently a minimum of 1 pulse shift exists between the gates information (Amplitude/TOF) and the corresponding alarms.

For instance, when the alarm filter of gate 1 is set at 10, 10 successive detections are necessary before the DET bit of gate 1 (bit 1 of byte 10) is active. This bit will be set on the eleventh pulse. Storage will then start from that pulse (if Pre-Post trigger = 0).

If you need to see the 10 preceding pulses, then set Pre-post trigger > 10.
