DLL description

 

Since version 5.0, several functions have been designed to achieve USPC data acquisition(Amplitude, TOF/WT, A-scan).

These functions work like classic functions for acquisition board. We can acquire a fixed number of data or continuously.

 

Functions list:

PCXUS_ACQ_CONFIG: to define your acquisition conditions(data to acquire, buffer size and start/end conditions)

PCXUS_ACQ_GET_STATUS: to get status

PCXUS_ACQ_START: to start acquisition and set the numbers of Scans to acquire

PCXUS_ACQ_READ: to read your data

PCXUS_ACQ_STOP: to stop acquisition

PCXUS_ACQ_CLEAR: to clear your configuration

Principe of data transfer

 

The principal problem to acquire data in Windows environment is: “not always use the CPU time”. Because Windows must do many others tasks.

 

Two methods are using with USPC to preserve the CPU time:

-          Large FIFO on board,

-          Data are transferred into PC memory in bus master mode (DMA).
