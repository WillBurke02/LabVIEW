PCXUS_ACQ_START.htm

Update 26 September 2006

 

Compatibility:

Platforms: Windows 2000/NT4/XP (unsupported on Windows 98)

 

Function:

ULONG WINAPI PCXUS_ACQ_START(ULONG hPCXUS, int Board, int NumberOfScansToAcquire)

 

Description:

This function starts acquisition.

If acquisition conditions are defined and PrePostScans equal N (N: 0 to 16) then the acquisition only starts N Scans before data condition occurs.

 

Arguments:

HPCXUS                                  Your access number (see PCXUS_Open function).

Board                                       Board number to be set up( 0 to 9).

NumberOfScansToAcquire         define the number of scans to acquire

                                                           Negative value: acquire infinitely

                                                           0: stop when buffer is full

                                                           Positive value:  acquire exactly this number of Scans (this value can be greater than buffer size, but in this case, you must read buffer before it is full)

 

Remark:

USPC board uses a pipe to put data into the internal FIFO buffer.

The length of this pipe is 5.

So, to acquire 100 data you need a minimum of 105 shots.

This number could increase according to the following cases:

·         Number of active channels  > 1 then you have to add 2 shots.

·         Pre/post scans > 1 then you have to add Pre/Post scans value * number of active channels shots.

 

 

 

Returns:

0                      no error

0x81000100      board number error

0x81000C00      access number error

0x81000C08      access number error (this board is configured by another application) (This error code is managed since DLL 10.0.0)

0x8100000B      acquisition not configured

0x8100000C      acquisition is running yet

0x8100004x      communication error
