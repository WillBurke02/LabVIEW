PCXUS_read_Ascan.htm

Update  20 October 2005

 

DLL Version 8.1.x

 

Compatibily:

DLL version: from 4.0 (previous version are not compatibles !)

 

 

Function:

ULONG WINAPI PCXUS_ACQ_ASCAN( int Board, int Test, ULONG *A_scan, int Timeout)

 

Description:

This function read an A-scan

 

Arguments:

Board               Board number (0 to N)

Test                 Test number (0 to 7) (only for USPC with MUX extension)

A_scan             A-scan array (see detail)

Timeout            define timeout (ms)

 

Returns:

0 if no error
