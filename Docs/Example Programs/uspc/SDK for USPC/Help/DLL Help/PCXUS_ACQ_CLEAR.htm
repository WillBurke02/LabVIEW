PCXUS_ACQ_CLEAR.htm

Update 26 September 2006

 

Compatibility:

Platforms: Windows 2000/NT4/XP (unsupported on Windows 98)

 

Function:

ULONG WINAPI PCXUS_ACQ_CLEAR(ULONG hPCXUS, int Board)

 

Description:

This function clears acquisition configuration.

You must call PCXUS_ACQ_CONFIG before to restart a new acquisition.

 

Arguments:

HPCXUS                       Your access number (see PCXUS_Open function).

Board                            Board number to be set up( 0 to 9).

 

Returns:

0                      no error

0x84000100      board number error

0x84000C00      access number error

0x84000C08      access number error (this board is configured by another application) (This error code is managed since DLL 10.0.0)

0x8400004x      communication error
