Install

 

1 - Minimum PC configuration

2 - USPC CARDS DRIVER installation

            2.1 - Windows 2000/XP

            2.2 - Windows NT4

3 -USPC CARDS API (Application Program Interface) software installation

4 - Run SOCOMATE API software to control settings, display A-scan scope and get Alarms/Amplitude/Distance measurement read-out

5 - Run ACQ SOCOMATE software for High Speed A/B & CSCAN data acquisition

6 - Update USPC Cards Software

 

1) Minimum configuration

 

·         256MB RAM

·         ATX POWER SUPPLY with 3.3 Volts

·         CD Driver

·         free 1/1 full length PCI slot per board

·         Max. consumption per board:

                                     3.3 V......1.5 Amp.

                                     5.0 V......1.0 Amp.

                                     +12 V......0.5 Amp.

                                     -12 V......0.1 Amp.

 

2) USPC3100 DRIVER Installation

 

2.1) Windows 2000/XP

 

·         turn off the PC

·         insert your USPC3100 card in a 1/1 full size PCI slot

·         turn on the PC

           

·         Log on as Administrator or as a user with administrative privileges

 

            ........Operating System detects a new PCI card......

 

·         put the USPC3100 Install Software CDROM in the right device (E:/, D:/,……..)

·         select specific localization : d:\Driver\Win2000_XP

·         click "next" till USPC Card Driver is fully installed

·         Go to "Device Manager" and verify the Card Driver is well installed:

                        - SIWDM:

                                   SIWDM            OK!

                        - SIWDM:

                                   SIWDM?           CONFLICT!

                                                           Verify in "Device Manager" that all other devices are well installed

and do not come in conflict with USPC3100 Driver.

Plug the board in another PCI slot

Use another PC

 

                        - (No device)      NOT OK!

                                                           Verify the card is properly plugged in slot

                                                           Plug the card in another PCI slot

Use another PC        

 

2.2) Windows NT4

 

·         turn off the PC

·         insert your USPC3100 card in a 1/1 full size PCI slot

·         turn on the PC

·         Log on as Administrator or as a user with administrative privileges

·         Run D:\driver\winnt4\USPC 3100 Installer.exe (if D: is your CDROM device)

and make sure the USPC3100 card Driver is well installed : SIDRV

4) Run SOCOMATE API software for settings & A-scan scope

 

·         C:\uspc\applications\pcxus.exe

·         Error message: "Card S/N not found"

Verify S/N in pcxus.ini file that must correspond to Cards S/N into the same PC  

USPC3100 Card could be suspected of failure, change it as well as S/N in pcxus.ini file.

·         Error message: "Error in Step,.........on Board N°"

Verify you use an ATX supply with 3.3Volts

Verify ATX supply consumption when several cards into the same PC

Run the API Software again

Change the Board in Error

If all boards in Error, use another PC.

Send PC with Board(s) to Socomate International.

 

5) Run ACQ SOCOMATE software for A/B&CSCAN data acquisition

 

·         C:\uspc\applications\acquisition.exe

                     Remove   will clean up the oldest version with access to the next step as:

                                                 Typical, custom or complete options.
