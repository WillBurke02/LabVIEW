USPC ActiveX component version 1.0

 

 

BorderStyle property

 

Description:

Returns/sets a value that determines whether border is none or single

 

Value:

0                    none

1                    single

           

Samples

 

Visual Basic:

Xuspc1.BorderStyle = Border_single
