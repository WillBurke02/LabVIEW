USPC ActiveX component version 1.0

 

 

AutoRedraw property

 

Description:

Returns/Sets a value that determines whether update A-scan method is automatic or not.

 

Value:

True      A-scan are updated automatically

False    A-scan are not updated automatically (you must use USPC_Display method to update)
