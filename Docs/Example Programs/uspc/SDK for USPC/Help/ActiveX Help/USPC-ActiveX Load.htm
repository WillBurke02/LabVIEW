USPC_Load method

 

Function:

Public Function USPC_Load(ByVal Server As String, ByVal Board As Long, ByVal Channel As Long, ByVal file As String) As Long

 

Description:

This function Loads a file into USPC boards

 

Arguments:

Server               server name ( “” when no server is using)(*)

Board               Board number to be loaded (-1 = all boards)

Channel            Channel to be loaded (-1 = all channels) (only for USPC with MUX extension)

File                  ASCII file name

 

Returns:

0 if any error

 

Note:

(*) Do not use network capabilities with this version of component. The network capabilities are testing and some bugs are not solved.

Use network capabilities with next version.
