USPC ActiveX component description

 

When you must develop an application with USPC boards you can use the DLL or the ActiveX component.

 

The DLL supplies all necessaries functions to control USPC boards installed on the PC.

The ActiveX component supplies all functions too, and it supplies an graphic interface to display one or several A-scan(see figure 3).

And more, with the ActiveX component you can control USPC boards installed on the PC (see figure 1) and/or others PC on the network(*) (see figure 2) (each PC on the network needs a server program called “ServerUSPC”).

 

Typically, if you want display one or several A-scans into your application and/or you want control USPC by a network(*), we suggest you to use the ActiveX component.

If you use only one PC and you don’t need to display A-scan, we suggest to use the DLL.

 

Note:

(*) Do not use network capabilities with this version of component. The network capabilities are testing and some bugs are not solved.

Use network capabilities with next version.
