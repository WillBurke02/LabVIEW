USPC_Read method

 

Function:

Public Function USPC_Read(ByVal Server As String, ByVal Board As Long, ByVal Channel As Long, ByVal unit As Long, ByVal strParam As String, ByRef dblValue As Double, ByRef dblT1 As Variant, ByRef dblT2 As Variant, ByRef strValue As Variant) As Long

 

Description:

This function reads a parameter into a USPC board

 

Arguments:

Server               Server name ( “” when no server is using)(*)

Board               Board number (0 to N)

Channel            Channel number (0 to 7) (only for USPC with MUX extension)

Unit                  0 = µs ; 1 = mm ; 2 = inch

StrParam          Parameter name ( see the list )

DblValue           Pointer to parameter value

DblT1               Parameter array 1

DblT2               Parameter array 2

StrValue           String parameter value

 

Returns:

0 if any error

DblValue or DblT1 or DblT2 or StrValue is updated.

 

Note:

(*) Do not use network capabilities with this version of component. The network capabilities are testing and some bugs are not solved.

Use network capabilities with next version.
