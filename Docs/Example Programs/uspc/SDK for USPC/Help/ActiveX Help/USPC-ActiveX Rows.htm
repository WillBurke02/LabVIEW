USPC ActiveX component version 1.0

 

 

Rows property

 

Description:

Returns/Sets a value that determines the number of rows into ActiveX to display A-scans when AscanAutoSize is ON.

 

Value:

Number of rows (1 to 8)

 

See Also:

AscanAutoSize property  | Cols property

 

Samples

 

Visual Basic:

‘Show 3 A-scans on single line

Xuspc1.AscanNumber = 3

Xuspc1.Rows= 1

Xuspc1.Cols = 3
