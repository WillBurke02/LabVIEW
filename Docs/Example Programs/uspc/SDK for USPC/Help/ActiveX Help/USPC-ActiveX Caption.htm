USPC ActiveX component version 1.0

 

 

AscanCaption method

 

Function:

Public Function AscanCaption(ByVal iAscan As Integer, ByVal Caption As String) As Integer

 

Description:

This function defines caption

 

Arguments:

IAscan                         Ascan number (0 - 15)

Caption                        Caption of Ascan

 

Returns:

0 if any error

 

Remark:

The caption is visible when AscanCaptionVisible property is True

 

See also:

AscanCaptionVisible property | AscanCaptionColor property

 

Samples

 

Visual Basic:

            ‘ Display 2 Ascans

            Xuspc1.AscanNumber = 2

            ‘ Define first Ascan with: board 0, channel 0 on local PC

Xuspc1.AscanSource 0, 0, 0, ””

Xuspc1.AscanCaption 0, “Channel: 70°”

 

 

 

             ‘ Define second Ascan with: board 0, channel 0 on PC_USPC
