USPC_Display method

 

Function:

Public Sub USPC_Display()

 

Description:

This function refreshes A-scans

 

Arguments:

No argument

 

Returns:

No returned value.

 

Remark:

If you want to refresh continuously A-scan, we suggest to set AutoRedraw property to True
