Deployment information

 

 

In order to deploy your own application written with SDK-USPC:

 

You have to deploy following files:

 

            Dll_pcxus.dll                 (destination c:\windows\system)                       

            Pcxus.ini                      (destination « Your directory »)  

            Pcxus.txt                     (destination « Your directory »)  

            Config_xxx.dat              (destination « Your directory\config »)    

            Config_yyy.dat              (destination « Your directory\config »)    

            Config_zzz.dat              (destination « Your directory\config »)    

 

These files are installed from Socomate CD on your computer when you selected a typical, complete installation or custom installation with

DLL, Applications and Configuration selected.

 

Files for USPC ActiveX component

 

ActiveXUspc.ocx           (destination c:\windows\system32)        

Cwui.ocx                      (destination c:\windows\system32)        

Lkdynam.dll                  (destination c:\windows\system32)

Mesa.dll                       (destination c:\windows\system32)

Mfc42.dll                      (destination c:\windows\system32)

Msvcp60.dll                  (destination c:\windows\system32)

Msvcrt.dll                      (destination c:\windows\system32)

Nids.dll                         (destination c:\windows\system32)

Ninetbrw.ocx                 (destination c:\windows\system32)

Stdole2.tlb                    (destination c:\windows\system32)

 

ActiveX files are installed from Socomate CD on your computer when you selected a complete installation or custom installation with USPC activeX selected.

                       

You have to set Windows registry

 

            HKEY_LOCAL/MACHINE/SOFTWARE/USPC/InstallPath=”your directory “

 

You have to change paths into PCXUS.INI and PCXUS.TXT files according to your install directory.
