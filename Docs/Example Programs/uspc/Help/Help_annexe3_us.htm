Files

 

Essential files to run the USPC 3100 program:

 

In WINDOWS directory (WINNT for Win NT and Windows for Win9x)

 

PCXUS.INI                                main configuration file

PCXUS.TXT                              language file

PCXUS Recent files                  list of last used UT files

 

In sub directory SYSTEM of WINDOWS

DLL_PCXUS.DLL                      library

 

In directory C:\USPC\CONFIG

 

CONFIG1.DAT                          secondary configuration file

CONFIG2.DAT                          “

CONFIG3.DAT                          “

 

Note :

You may install the CONFIGx.DAT files into another directory, in a such case make sure to change the files path in PCXUS.INI main configuration file

(boot section).

 

[boot]

 

CONFIG1_default=c:\uspc\config\config1.cod

CONFIG2_default=c:\uspc\config\config2.cod

CONFIG3_default=c:\uspc\config\config3.cod

 

In sub directory SYSTEM32\DRIVERS of WINDOWS

 

SIWDM.SYS                            driver
