Trigger

Description

This parameter selects the triggering origin of Gate 1(or 2)

 

 

Selection

Gate1:

-          Inactive

-          Initial pulse

-          Interface echo

-          Start IF

 

Gate 2:

-          Inactive

-          Initial pulse

-          Interface echo

-          Echo Gate 1

-          Start IF

 

 

 

See also :

[Mode] [Alarm filter] [Alarm filter level] [Peak amplitude] [Wave] [Start] [Width] [Level] [TOF/WT] [Summary]

 

Mode

Description

This parameter selects the detection mode of signals in the Gate

 

 

Selection

Positive (any signal over the Gate level should be detected)

Negative (any signal below the Gate level should be detected)

 

 

Remark

The Gate must be violated an adjustable number of consecutive shots before forcing the ON/OFF output state switching (See Alarm filter and Alarm filter level).

Negative mode sets “Alarm filter level” to 0 dB.

 

See also :

Alarm filter

Description

This parameter filters the alarm detection of signals by setting the number of shots with consecutive violations of the Gate to force switching the Gate 1 (or 2) ON/OFF output on alarm position.

 

 

Min

1

Max

30

 

 

Example

You select 10 and you are in positive mode. A signal must appear 10 consecutive time in and over the Gate level to activate the alarm output.

 

 

 

See also :

[Trigger] [Alarm filter level] [Mode] [Peak amplitude] [Wave] [Start] [Width] [Level] [TOF/WT] [Summary]

 

Alarm filter level

Description

This parameter sets relative level for alarm detection.

 

 

Min

-15 dB

Max

0 dB

 

 

Example

If you set “alarm filter” to 3, “gate level” to 80% and “alarm filter level” to –3dB then Alarm output will be “ON” when 3 consecutives detections pass over 40 % and at least one detection over 80%.

 

No pulse over alarm filter level or gate level.

 

=> Alarm = OFF(*)

 

One pulse over alarm filter level.

 

=> Alarm = OFF(*)

 

Two pulses over alarm filter level.

 

One pulse over the gate level.

 

=> Alarm = OFF(*)

 

Three pulses over alarm filter level.

 

One over the gate level.

 

=> Alarm = ON(*)

 

Alarm = OFF(*)

 

(*) Alarm is always updated on the next pulse

 

Remark:

This parameter is only working with Alarm mode = Positive detection.

Peak amplitude

Description

This parameter indicates the signal peak to be used in the Gate for peak amplitude measurement.

 

 

Selection

1) Max. peak. in the Gate

2) First peak in the Gate

 

(Gate_amplitude.gif)

 

 

Remark

This parameter is disabled when a MUX board is used

 

 

See also :

Wave

Description

This parameter selects the wave(s) that will be used to detect a signal (Alarm), measure the signal amplitude and, stop the TOF measurement from initial or interface signal, or start the TOF from Gate 1 to Gate 2 when Gate 2 in Echo-Gate trigger (echo to echo TOF)

 

 

Selection

Positive wave

Negative wave

Full wave

RF

 

 

Remark

Full wave and RF modes are both detecting, in the same way, on positive or negative waves.

Start

Description

This parameter set the position of the start of Gate 1 (or 2) from the initial pulse or interface trigger:

As well as the position of the start of Gate 2 from the signal in Gate 1 when “echo Gate” trigger has been selected in Gate 2 settings.

 

 

Min

Gate 1 = 0.4 µs; Gate 2 =  0.08 µs

Max

655 µs

Resolution

20 ns

 

 

Remark

Example

(Gate_position.gif)

 

Gate 1 start is at 50 mm when triggered from main bang (1) or 20 mm when triggered from interface signal (2).

 

If high resolution is ON then gate must be set between 0 up to 301 µs.

(see pcxus.ini file to get more information about resolution setting)
