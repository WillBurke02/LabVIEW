Mode

Description

Selection of pulser trigger mode

 

 

Selection

Internal synchro.

External synchro.

 

 

Remark

The repetition rate of square wave pulser is limited to

20 – 20000 Hz, internal trigger

0 – 20000 Hz, external trigger

See Post trigger (Offset) information when external mode is setting.

Power

Description

Selection of pulse voltage

 

 

Min

125 Volts

Max

250 Volts

 

 

Remark

To protect the PC card from severe damages, a transmitter control is made each time you modify this parameter. According to the parameters combining: power/frequency/rep.rate, you might not be allowed to modify this parameter as you wanted to. A warning message will tell you that the power selected has not been taken into account.

 

(Pulser_picture2_us.gif)

 

The following formula is used for this control :

The voltages are specified for a load of 50 Ohms.

The pulse falling time is 5 nsec.

Offset

Description

This parameter set the time delay between the card PRF IN trigger and the pulser firing. This parameter is useful when several boards are working.

 

 

Min

0 µs *

Max

300 µs

Resolution

1.28 µs

Remark

Offset is enabled only when External trigger is selected.

(*)This offset  is 8.52µs if value is in range : [0; 11.10µs[

Repetition rate

Description

This parameter set the pulse repetition frequency or pulse repetition rate (PRF or PRR)

 

 

Min

50 µs (500 µs for USPC 3200 P)

Max

20000 µs

Resolution

1 µs

 

 

Remark

To protect the PC card from severe damages, a transmitter control is made each time you modify this parameter. According to the parameters combining: power/frequency/rep.rate, you might not be allowed to modify this parameter as you wanted to.

Another limitation is set according to the end of  gates or display time.

 

(see more details about PRF limitations)

 

 

When a low version of MUX card is used, global frequency is divided by number of actives tests.
