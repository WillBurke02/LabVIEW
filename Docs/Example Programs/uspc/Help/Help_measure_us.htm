TOF/WT

 

There are two measurement modes:

 

Output mode

Description

This parameter selects TOF or WT mode.

 

 

Selection

Min/Max ON/OFF alarms and TOF outputs

Min/Max ON/OFF alarms and WT outputs

 

 

Remark

Min/Max ON/OFF alarms and WT outputs mode is not active with the MUX software.

TOF and WT common parameters

 

Measure origin

Description

This parameter set the Origin and End of TOF or Wall Thickness measurement.

When Gate IF, 1 and 2 are triggered on Initial Pulse, you set only the End of measurement.

When Gate 1 and 2 are triggered on “Interface echo” from IF Gate, you set Origin of measurement from IF Gate and End of measurement from Gate 1 & 2.

When Gate 2 is triggered on “echo-gate” from Gate 1, you set Origin of measurement from Gate 1 and End of measurement from Gate 2.

 

 

 

Selection

-          Level: first crossing point of Gate with the selected Waveform (Point 1)

-          Zero: first zero-crossing point after the Maximum Peak of the selected Waveform over the Gate threshold (Point 3)

-          Peak: Maximum Peak point of the selected Waveform over the Gate threshold (Point 2)

-         Like Amp : Maximum Peak point inside the Gate, from 0% up to 100% (Point 4)

 

Peak amplitude = First peak

(Gate_Measure_origin_&_first_peak.gif)

 

Peak amplitude = Max peak

(Gate_Measure_origin_&_max_peak.gif)

 

(Gate_Measure_origin_on_max_amplitude.gif)

 

Remark

Option “Like Amp.” is only enabled when Peak amplitude mode = Max. peak.

Option “Level” is only enabled when Peak amplitude = First peak.

Alarm filter

Description

This parameter filters the max and min alarm measurements of time by setting the number of shots with consecutive violations of thresholds to force switching the Gate 1 (or 2) ON/OFF output on alarm position.

 

 

Min

1

Max

30

 

 

Example

You select 10; the measurements must be 10 consecutive times over the max alarm or below the min alarm to activate the max or min ON/OFF outputs of the Gate.

Output offset

Description

This parameter adjusts the zero position of the TOF analog output, from the trigger signal (readout according to the unit selected).

 

 

Min

40 ns

Max

1.31 ms

 

 

Resolution

5 ns

 

 

Remark

This parameter is very useful to optimize the analog output dynamic.

Example:

The Gate start is 10 mm and the Gate width is 10 mm. The output dynamic has been set to 20 mm.

If the offset is 0, the analog output will move only from 2.25 volts to the max 4.5 volts.

If the offset is 10 mm, and output dynamic is 10 mm as well, the analog output will move within all the dynamic output range from 0 to 4.5 volts.

 

 

See also :

[Measure point] [Max. TOF/WT] [Min. TOF/WT] [Alarm filter] [Multi-echo] [Calibration] [Velocity] [Output dynamic] [WT] [Resolutions] [Summary]

 

Output dynamic

Description

This parameter adjusts the output range of the TOF analog output, from the zero position (output offset) (readout according to the unit selected).

 

 

Min

1.28 µs

Max

1.31 ms

 

 

Resolution

Variable

 

 

Example

The output dynamic has been set on 10 mm and the output offset is 0; then the analog output will move from 0 to 4.5 volts if a signal in the Gate moves from the zero position to 10 mm.

Remark

The resolution is optimized according to TOF parameters. Also, the true output dynamic is displayed next to the adjustable value. (ex: 40 mm => 40.80 mm)

Resolutions

 

(Measure_picture8_us.gif)

 

Resolution of measurement:

Depend on resolution mode High or Low (see PCXUS.INI file) and Multi-echo.

(Minimum resolution is 5ns/Multi-echo).

 

Resolution of calculation:

For TOF mode: Depend on alarms positions, output offset, output range, multi-echo and calibration.

(Minimum resolution is 5ns/Multi-echo).

For WT mode: Depend on process limits, multi-echo and calibration.

(Minimum resolution is 0.078ns).

 

Resolution of analog output:

            Maximum value between Output range / 256 and Resolution of calculation.
