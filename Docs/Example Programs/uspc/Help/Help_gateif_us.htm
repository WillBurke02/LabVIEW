GATE IF(Interface Gate)

 

This gate is used to keep watching on the interface signal or any signal into the Gate and to trigger Gate 1, gate 2 and Ascan display from this signal

 

(Gateif_picture1_us.gif)

 

[Trigger] [Mode] [Alarm filter] [Wave] [Start] [Width] [Velocity for gate IF] [Level] [TOF/WT][Summary]

 

Trigger

Description

This parameter selects the triggering origin of the interface Gate

 

 

Selection

Inactive

Active on initial pulse

 

 

See also :

[Mode] [Alarm filter] [Wave] [Start] [Width] [Level] [Summary]

 

Mode

Description

This parameter selects the detection mode of signals in the Gate.

 

 

Selection

-          Positive (any signals over the Gate level should be detected)

-          Negative (any signal below the Gate level should be detected)

 

 

Remark

The Gate must be violated an adjustable number of consecutive shots before forcing the ON/OFF output state switching (See Alarm filter).

 

Main use: coupling alarm.

 

See also :

[Trigger] [Alarm filter] [Wave] [Start] [Width] [Velocity for gate IF] [Level] [TOF/WT] [Summary]

             

Alarm filter

Description

This parameter filters the detection alarm of signals by setting the number of shots with consecutive violations of the Gate to force switching the interface Gate ON/OFF output on alarm position.

 

 

Min

1

Max

30

 

 

Exemple

You select 10 and you are in positive mode. A signal must appear 10 consecutive time in and over the Gate level to activate the alarm output.

See also :

[Trigger] [Mode] [Wave] [Start] [Width] [Velocity for gate IF] [Level] [TOF/WT] [Summary]

 

Wave

Description

This parameter selects the wave(s) that will be used to detect a signal (Alarm), and start the TOF measurement

 

 

Selection

Positive wave

Negative wave

Full wave

RF

 

 

Remark

Full wave and RF modes are both, detecting in the same way, on positive and negative waves.

See also :

[Trigger] [Mode] [Alarm filter] [Start] [Width] [Velocity for gate IF] [Level] [TOF/WT] [Summary]

           

Start

Description

This parameter set the position of the start of interface Gate from the initial pulse.

 

 

Min

0.08 µs

Max

655 µs

Resolution

20 ns

 

 

Remark

The start position depends on the Gate triggering mode.

 

If high resolution is ON then gate must be set between 0 up to 301 µs.

(see pcxus.ini file to get more information about resolution setting)
