Input attenuator

Description

This parameter allows to use a 15 dB input  attenuator with 50 Ohms impedance.

This attenuator should be used in case of high input signals which might insert non linearity and saturation problems.

 

 

Selection

Gain 2

Description

This parameter set a gain, according to main Gain 1, which is applied after the DAC area

 

 

Min

-70 dB

Max

70 dB

 

 

Resolution

0.1  dB

 

 

Remark

This parameter is quite often used to attenuate a saturated back wall echo when the DAC is active.

Limits:

-          the real gain applied after the DAC curve is limited to the dynamic 0-70 dB. Therefore, if the Gain 1 is 10 dB and the Gain 2 is set at –70 dB, the real gain after DAC will be 0 dB (and not – 60 dB).

-          The DAC slope is +/- 40 dB/µs. Therefore, the necessary time to reach the real gain after the DAC curve will only depend on the gain distance between the last gain of the DAC curve and the real gain after this DAC curve. Example : the last gain of the DAC curve is 50 dB, and the Gain 2 has been set to get 30 dB after this DAC curve, so it will last 0.5µs to drop down from 50 to 30 dB.
