Display mode

Description

This parameter selects the digital AScan display mode

 

 

Selection

-          Max. Peak (the digital AScan display is made up with all the ultrasonic signals occuring between two AScan display software commands.

-          Snapshot (the digital AScan display is the one the A-scan display software is catching at the command.

Remark

Max. peak mode is disabled when a MUX is connected.

Delay

Description

This parameter set the time or distance delay of the AScan display from the triggering origin.

 

 

Min

0 µs

Max

655 µs

Resolution

20 ns

 

 

Remark

If high resolution is ON then delay + range  must be set between 0 up to 301 µs.

(see pcxus.ini file to get more information about resolution setting)

Full display

Description

This button toggles range to “normal” range and “extend” range.

Extend range is used to display a complete A-scan from initial pulse to last echo.

 

 

 

 

Remark

Scope trigger is switched on Initial Pulse and Scope offset is set to zero when you select “Full display”. You will retrieve previous trigger and offset when you come back to normal display.

You could adjust the extend range. To do that you have to use “Range” control such as you do for normal range.

Reject

Description

This parameter set the  real UT signal rejection threshold. All analog signals below this threshold should not be digitised and therefore not displayed.

 

 

Min

0 %

Max

50 %

Resolution

1 %

Remark

This parameter could be useful to erase the noise
