DAC

 

(Receiver_picture2_us.gif)

 

Description

The DAC allows to create a depth gain correction according to time.

The DAC curve is defined and limited within the DAC Gate (dark pink aera)

The first gain of the curve is always the same as the main Gain 1, this means all variation of the main gain leads the move of all curve (like an offset).

 

 

Dynamic

70 dB

Max. slope

+/- 40 dB/µs

 

 

 

To create a DAC curve, two ways:

-          keyboard setting, element per element on DAC panel,

-          echo dynamic setting with cursors, click on “Dyn. Correct."

 

To display  the DAC curve, click on “Curve”.

To erase all elements of the curve, click on “reset”.

To define DAC area, use Trigger mode, Start and Width parameters.

 

Keyboard setting, element per element

On the DAC panel pink display, click on dB or depth rectangle according to the element you want to set up (no readout in rectangles) or modify (readout in rectangles): a “DAC point.vi” window appears.

 

There was no readout in rectangles (xxx):

Type the gain variation you wish and the relative depth of element from the first one.

Click on “Addition” to confirm or “cancel”.

 

(Receiver_picture3_us.gif)

 

There was readout in rectangles:

-          Erase both readout of the element.

-          Type a new gain and/or depth and click on “remove” to confirm or,

-          “cancel”

 

(Receiver_picture4_us.gif)

 

 

Remark: This way is mostly used when the material attenuation is well known.

 

Echo dynamic setting

To use this method, the DAC must first be active: click on “DAC” to get a green light.

Then click on “Dyn. Correct.” To display a set of tools and utilities on the control panel and the A-scan signal window.

 

On Ascan window:

-          One blue horizontal cursor to set the correction level of one echo

-          One grey vertical cursor to set the area of echo to be corrected.

-          One red square spot showing the peak of echo to be corrected.

 

On control panel:

-          One digital control rectangle of the grey vertical cursor size (% of DAC Gate)

 

To create one element:

-          move the blue cursor with the mouse to the requested level of correction.

-          Move the grey cursor with the mouse over the area of the signal to be corrected.

-          When the red spot get onto the signal peak you want to correct, click on “Addition”.

 

The DAC may fail in the following conditions:

-          the DAC requested means a variation upper then 40 dB/µs.

-          the DAC requested means a corrected gain higher than the dynamic gain.

 

In both conditions, the DAC will fail with an error message.

           

trick:

 

You may combine both methods to create the DAC curve.

To erase one element, click on this element in the DAC panel and click on “Erase”.

Slope adjust. (value)

Description

This parameter set the slope adjusting value (dB/µs or dB/mm or dB/in).

This slope is added to DAC curve when slope adjust button is ON.

 

Min/Max

No input limit.

But, if slope of DAC and slope adjusting is over +/- 40 dB/µs then the real correction will be limited by the hardware.

 

Remark:

This parameter is useful if you control homothetic pieces. You have to create a DAC curve on one piece and only adjust slope value for others pieces.
